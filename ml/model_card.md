# Model Card: прогнозирование продаж Rossmann

## 1. Назначение модели
Модель предназначена для ежедневного прогноза продаж (`sales`) по каждому магазину (`store_id`) с горизонтом по умолчанию 30 дней.

## 2. Данные
- Источник: Kaggle Rossmann Store Sales.
- Уровень гранулярности: день × магазин.
- Входные признаки включают лаги, скользящие средние, календарные признаки, флаги промо/праздников и признаки магазина.

## 3. Кандидаты моделей
- Базовая: `Ridge`.
- Продвинутая: `CatBoostRegressor`.
- Выбор лучшей модели выполняется по минимальному RMSE на отложенной временной выборке.

## 4. Метрики
- MAE
- RMSE

## 5. Ограничения
- Точность зависит от качества ETL и полноты истории по магазину.
- Рекурсивное прогнозирование может накапливать ошибку на длинном горизонте.

## 6. Этические и бизнес-риски
- Модель не учитывает внешние события (экономические шоки, маркетинговые кампании вне датасета).
- Использовать как инструмент поддержки решений, а не единственный источник планирования.
