# Концепция ВКР

## Тема
**«Разработка модели прогнозирования продаж для аналитической платформы интернет-магазина»**.

## Актуальность
В условиях высокой конкуренции e-commerce компании нуждаются в оперативной аналитике продаж и инструментах краткосрочного прогнозирования. Традиционная ретроспективная отчётность не позволяет быстро адаптироваться к колебаниям спроса, сезонности и промо-активностям. Проект направлен на создание единой аналитической платформы, объединяющей хранение данных, BI-метрики, ML-прогнозирование и web-интерфейс.

## Объект и предмет исследования
- **Объект:** процессы анализа и прогнозирования продаж в розничной сети.
- **Предмет:** методы построения DWH, ETL-пайплайна и ML-моделей для ежедневного прогноза по магазинам.

## Цель
Разработать E2E-систему, обеспечивающую загрузку сырых CSV-данных Rossmann, их преобразование в аналитическую модель данных (звезда), построение KPI-представлений, обучение и публикацию модели прогноза через API и визуализацию в React Dashboard.

## Задачи
1. Спроектировать хранилище данных по схеме «звезда» (Kimball-ориентированный подход).
2. Реализовать идемпотентный ETL-процесс загрузки и очистки данных.
3. Реализовать контроль качества данных (пропуски, дубликаты, целостность FK).
4. Построить признаки временного ряда (лаги, rolling-агрегаты, календарные признаки).
5. Обучить и сравнить базовую и продвинутую модели прогноза.
6. Развернуть REST API на FastAPI.
7. Создать web-дашборд для мониторинга KPI, аналитики по магазинам и запуска прогноза.

## Научная новизна и практическая значимость
- Практическая новизна состоит в объединении BI и ML в единой архитектуре «данные → модель → API → UI».
- Решение может быть адаптировано к реальным данным интернет-магазина и расширено новыми источниками.

## Ожидаемые результаты
- Репозиторий с воспроизводимым запуском на Ubuntu 24.04.
- PostgreSQL DWH с витринами KPI.
- ML-модель с метриками MAE/RMSE и model card.
- FastAPI эндпоинты для аналитики и прогноза.
- React dashboard для конечных пользователей.

## Распределение ролей
- **Developer A:** DWH, ETL, ML, backend API (инференс).
- **Developer B:** React-приложение, UX, интеграция API, визуализации.
