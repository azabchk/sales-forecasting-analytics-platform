# План работ (milestones)

## Этап 1. Подготовка и проектирование
- Анализ датасета Rossmann.
- Проектирование схемы звезды и KPI-витрин.
- Согласование API-контракта.

## Этап 2. Реализация DWH + ETL
- Создание SQL-скриптов схемы, индексов и views.
- Реализация `etl_load.py` и `data_quality.py`.
- Проверка идемпотентности загрузки.

## Этап 3. ML-пайплайн
- Формирование признаков.
- Обучение моделей Ridge и CatBoost.
- Оценка MAE/RMSE, сохранение артефактов.
- Подготовка model card.

## Этап 4. Backend
- Реализация FastAPI роутеров и сервисов.
- Подключение PostgreSQL и inference.
- Обработка ошибок, CORS.

## Этап 5. Frontend
- Каркас приложения на React + TS.
- Страницы Overview, Store Analytics, Forecast.
- Интеграция API и визуализация графиков.

## Этап 6. Интеграция и тестирование
- Smoke-тесты ETL/API/UI.
- Проверка корректности бизнес-метрик.
- Финальная документация.
